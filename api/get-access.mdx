---
title: "Get access"
description: "API keys are issued on request."
---

The Data API is not self-serve. To get a key, contact us first and tell us what you are building. We issue keys
by hand so we can size rate limits and data coverage to your use case.

<Steps>
  <Step title="Message us on X">
    Send a DM to [@perp_ag](https://x.com/perp_ag). Include:

    - who you are and what you are building,
    - which venues you need,
    - roughly how many requests per minute you expect, and
    - which endpoints or data you care about most.
  </Step>
  <Step title="We issue your key">
    We reply with an API key and the rate limit agreed for it.
  </Step>
  <Step title="Make your first call">
    Send the key in the `x-api-key` header. See [Authentication](/api/authentication).
  </Step>
</Steps>

<Tip>
  Need data we do not list here, a higher limit, or a bulk export? Ask in the same message. Many of the
  endpoints started as requests.
</Tip>
