The Perp.ag Data API gives you the analytics behind the app: every perp wallet we track on **Lighter, RH Lighter,
Jupiter, Phoenix, Bullet and Aftermath**, scored, ranked and broken down. If you are building a trading tool, a
dashboard, a research report or a bot, you can use the same numbers we use.

<Info>
  Access is by API key, issued on request. [Contact us](/api/get-access) to get one.
</Info>

## At a glance

| | |
| --- | --- |
| **Base URL** | `https://api.reperp.xyz/api/v1` |
| **Format** | JSON over HTTPS, gzip-compressed |
| **Auth** | `x-api-key` header. See [Authentication](/api/authentication). |
| **Venue** | `platform` query parameter: `LIGHTER`, `RHLT`, `JUPITER`, `PHOENIX`, `BULLET`, `AFTERMATH`. See [Venues and identifiers](/api/venues-and-identifiers). |
| **Rate limit** | 60 requests per minute by default. See [Errors and limits](/api/errors-and-limits). |

## A first request

```bash
curl "https://api.reperp.xyz/api/v1/wallet/discover?platform=LIGHTER&sort_by=copy_score&copy_score_tier=S&limit=10" \
  -H "x-api-key: $PERP_AG_API_KEY"
```

This returns the ten best S-tier Lighter wallets by Copy Score, with their 7D, 30D and all-time metrics.
